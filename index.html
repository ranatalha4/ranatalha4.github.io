Wazuh-playbooks

Practical playbooks for running Wazuh 4.14 in production: a custom VirusTotal IP lookup on FortiGate alerts, SentinelOne threat ingestion, custom rules and decoders, and CDB lists for IOC matching. Configs are pulled from a live manager by a redaction script, and every push runs CI checks for valid XML and JSON, rule ID collisions and leaked secrets across the full history.

ThreatScribe

An n8n workflow that turns a security news link posted in Slack into a client-ready threat advisory. It scrapes the article past redirects and bot walls, drafts a structured CTI analysis with an LLM, extracts severity, CVSS and CVEs, and posts a styled HTML report back into the thread. Analysts review and send instead of writing from scratch.

  • 11workflow nodes
  • 8report sections

ShiftRelay

An n8n workflow that automates SOC shift handovers. One Slack command reads the client's alert log from a SharePoint workbook through Microsoft Graph, dedupes and counts alerts by source, severity and status, then posts the full handover to the SOC's Slack channel and a client-facing summary to Microsoft Teams. The incoming shift is tagged automatically.

  • 12workflow nodes
